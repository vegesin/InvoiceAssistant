# 发票报销工具开发

# 任务背景
我当前有很多发票报销的工作，现在这些报销的文件整理会很繁琐，我现在希望开发一个自动化工具，充当我的发票报销助手

我现在的报销流程如下：
- 报销需要如下材料 ： 1、纸质版发票pdf 2、支付宝微信等对应的实际支付记录截图
- 发票pdf等文件会发送我的一个固定邮箱
- 我需要下载这个发票pdf 然后打印
- 然后创建一个word 把这些手机支付截图插入，然后在打印

- 针对没有发票的日常花销报销 ：这部分报销不需要发票，这部分报销只需要对应的支付记录截图，以及总金额
但是需要统计金额，我之前的报销需要在手机上长截图对应的花销，然后让一个ai给我算出来一个总金额

当前主要繁琐的地方如下：
- 多个发票的下载打印
- 支付记录截图需要我手动从手机截图，然后上传电脑，然后插入一个word，然后在打印这个word
- 发票报销的金额，发票是否报销不知道如何整理
- 对于差旅，一般报销是一个闭环，从A 到 B 从B 到A的机票/火车票 ，以及对应的酒店  ，针对这种，最后的报销金额还会出现出差补贴，一天有金额为N的补贴，最后打款是发票金额+天数*N的补助，每次我还要自己验算一下金额是否正确
